## About Me

> Full-stack developer who builds complete products, from pixel-perfect UI to production-grade backend systems and real-world deployments.

I'm **S M Samiul Hasan**, a Full-Stack Web & App Developer from Rangpur, Bangladesh. I don't just write code, I architect and ship complete digital products. My journey started at **Inspired IT Rangpur**, leveled up through **Programming Hero (Batch 12)**, and is now moving forward with the **Next Level AI-Driven Software Engineering** program.

I've built and deployed real platforms including **EZBid.cloud** (a B2B e-procurement and tender management system) and **Jamibd** (an AI-powered e-commerce platform), both running in production with real users. I manage my own Linux VPS, configure Cloudflare, handle Docker deployments, and patch server vulnerabilities when needed.

**What I do:**

- Build full-stack web apps with Next.js, TypeScript, Node.js, Python, and PostgreSQL
- Build cross-platform mobile apps with Flutter and Dart
- Automate data pipelines with Python, Playwright, and Selenium
- Deploy and maintain apps on VPS, Vercel, Cloudflare, and Docker
- Debug, fix, and maintain existing products end to end

> **Product engineering focus:** my strength is real-world development: debugging architectural issues, building features, and delivering production-ready software for web and mobile products.
